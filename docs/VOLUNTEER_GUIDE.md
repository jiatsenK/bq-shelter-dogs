# 志工資料維護說明：狗狗介紹與照片

網站上每張狗狗卡片可以顯示一張照片和一段介紹。這些資料由志工自己放在這個 repo 裡，**一隻狗一個檔案**，全程在 GitHub 網頁上操作，不用裝任何軟體。

名冊、遛狗日期、備註、同籠關係還是以 Google 試算表為準，這裡只放「介紹」和「照片」。

- 介紹檔放的是**狗剛入所時的原始狗卡內容與背景**，網站上顯示在詳細資訊的「狗卡資訊」。
- 之後觀察到的個性、與人互動、散步注意事項，請寫在試算表的「備註」欄（網站顯示在「備註」），不要寫進介紹檔，兩者分開保存。

---

## 1. 檔名一律用「編號」

| 放什麼 | 放在哪個資料夾 | 檔名 |
|---|---|---|
| 介紹 | `dogs/` | `{編號}.md`，例如 `202201678.md` |
| 照片 | `photos/` | `{編號}.jpg`，例如 `202201678.jpg` |

- **編號**就是 Google 試算表「主清單」的「編號」欄，入所時就固定、終身不變，換籠也不用改檔名。
- 不要用犬名當檔名，犬名可能重複或改名，網站只認編號。
- 檔名只能有數字編號和副檔名，不要加空白、括號或犬名。
- 沒有檔案的狗沒關係，網站會自動顯示預設圖示、略過介紹，不會出錯。

## 2. 介紹檔（`dogs/{編號}.md`）的寫法

直接複製 [`dogs/_範本.md`](../dogs/_範本.md) 的內容來改：

```markdown
---
name: 苗斯
id: 202201678
---
2025 年從街頭救援進來，個性親人，怕鞭炮聲……
```

- 最上面兩條 `---` 之間是基本資料，**兩條 `---` 都要保留**。
  - `name`：犬名，照主清單寫（方便人看，網站顯示的犬名還是以試算表為準）。
  - `id`：編號，要跟檔名一樣。
  - `formerIds`（選填）：同一隻狗被認養退回、再次入所時會拿到新編號。檔名和 `id` 用**新編號**，舊編號寫在這裡，例如 `formerIds: 2018041318`，有好幾個用逗號分開。網站會在詳細資訊標「第 2 次入所・首次入所日（舊編號）」，分析頁的在所時間從第一次入所算。照片、遛狗紀錄都用新編號。
- 第二條 `---` 下面就是介紹內文，寫純文字即可，幾句話就好，太長在手機上不好看。
- 不用寫遛狗日期、備註、同籠狗，這些網站會從試算表抓。

## 3. 照片（`photos/{編號}.jpg`）的規定

- **只接受 `.jpg`**，副檔名要小寫：`202201678.jpg` 可以，`202201678.JPG`、`.jpeg`、`.png`、`.heic` 網站都讀不到。
  - iPhone 預設拍出來是 HEIC：到「設定 → 相機 → 格式」選「最相容」，之後拍的就是 JPG；或用 LINE 傳給自己再存下來，也會變成 JPG。
- **建議尺寸**：正方形，約 **600 × 600 像素**（卡片上的縮圖是正方形，長方形照片會被裁掉上下或左右，狗要在正中間）。
- **檔案大小上限：300 KB**。手機原始照片通常有 2–5 MB，太大會讓志工在現場打開很慢，請先縮小再上傳。
  - 手機：用相簿的「編輯 → 裁切」裁成正方形，再用 LINE 傳給自己（選一般畫質）存下來，通常就會小於 300 KB。
  - 電腦（Windows 小畫家）：用「選取」框出正方形 →「裁剪」→「調整大小」選「像素」、勾「維持外觀比例」、水平輸入 600 →「另存新檔 → JPEG 圖片」。
- 一隻狗只放一張照片。

## 4. 在 GitHub 網頁上操作

需要先有 GitHub 帳號並登入。repo 網址：https://github.com/jiatsenK/bq-shelter-dogs

> 如果你不是這個 repo 的協作者，最後一步的按鈕會變成「Propose changes」，送出後需要管理者按「Merge」才會生效。

### 新增一隻狗的介紹
1. 打開 repo，點進 `dogs` 資料夾。
2. 右上角按 **Add file → Create new file**。
3. 上方檔名欄輸入 `編號.md`，例如 `202201678.md`。
4. 內容欄貼上 `_範本.md` 的內容，改成這隻狗的犬名、編號和介紹。
5. 按右上角綠色 **Commit changes...**，跳出視窗後選 **Commit directly to the main branch**，再按 **Commit changes**。

### 修改已經有的介紹
1. 在 `dogs` 資料夾點開那隻狗的檔案。
2. 按右上角的鉛筆圖示（Edit this file）。
3. 改完按 **Commit changes...** → **Commit changes**。

### 新增或換照片
> 網站開通照片上傳後（見 `docs/PHOTO_UPLOAD_SETUP.md`），最簡單的方式是在網站打開那隻狗的詳細資訊，按「上傳照片／更換照片」，選照片、預覽後按「確認上傳」，會自動用編號存好並縮小。下面是在 GitHub 網頁上傳的方式。

1. **先把照片檔名改成 `編號.jpg`**（GitHub 網頁上傳時不能改檔名）。
   - 手機：先把照片存到「檔案」App（iPhone）或「檔案管理」（Android），長按照片 → 重新命名。
   - 電腦：在檔案總管裡對照片按右鍵 → 重新命名。
2. 打開 repo，點進 `photos` 資料夾。
3. 右上角按 **Add file → Upload files**，把照片拖進去（或按 choose your files 選照片）。
   - 換照片時上傳同檔名的新照片，舊的會直接被取代。
4. 按下方綠色 **Commit changes**。

### 刪除（狗狗離所後可以不刪）
- 離所的狗不會出現在網站上（網站只顯示主清單上的狗），檔案留著也沒關係。
- 真的要刪：點開檔案 → 右上角「⋯」→ **Delete file** → **Commit changes**。

## 5. 上傳後多久會看到？

- 照片：送出後大約 1–3 分鐘網站會更新。
- 介紹檔：送出後會自動跑一次「同步試算表」，把介紹整理進網站資料，大約 2–5 分鐘網站會更新。

重新整理 https://jiatsenk.github.io/bq-shelter-dogs/ ，在卡片上看到照片、點開詳細資訊看到「狗卡資訊」就成功了。

看不到的話，依序檢查：
1. 檔名是不是跟試算表「編號」完全一樣（不要多空白）。
2. 照片副檔名是不是小寫 `.jpg`。
3. 介紹檔最上面兩條 `---` 有沒有都在。
4. 手機瀏覽器可能有快取，關掉分頁重開一次。

## 6. 「我溜過」：第一次要設定你是誰

網站的「我溜過」會列出你到所遛過的狗，靠的是試算表「誰遛的」欄。

1. 第一次打開「我溜過」會看到「你是誰？」，輸入你在試算表「誰遛的」寫的名字。有好幾種寫法（例如本名和暱稱）用頓號隔開，例如 `小明、明明`。
2. 按「設定」。名字只用來換成一串代號，代號記在這支手機，名字不會存下來，網站上也看不到。
3. 之後遛狗時在試算表「誰遛的」寫一樣的名字，同步後（台灣時間 7:00–22:00 每小時一次）就會出現在「我溜過」。

- 換手機、換瀏覽器或清除瀏覽器資料後要重新設定一次，紀錄不會不見。
- 要改名字：「我溜過」上方按「修改」。要清掉這支手機的設定：按「修改」後選「清除這支手機的設定」。
- 從這個功能上線那天開始記錄，之前的紀錄補不回來。同一隻狗在一小時內被兩個人遛，只會記到後面那個人。
