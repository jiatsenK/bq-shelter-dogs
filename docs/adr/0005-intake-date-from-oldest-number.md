# 0005 入所日照最舊編號算，舊編號誰都能補

日期：2026-10-16（K 決定）

> 部分被 ADR 0011 取代：沒有舊編號時可以補登舊入所日，入所日取三者裡最早的那天。

狗轉所、被認養退回或收容所整批換號時會拿到新編號，只看現在的編號，「入所多久」就會從頭算（例：墨西哥編號 2017090508，介紹寫 2015/8/18 入所）。K 決定入所日取這隻狗**所有編號裡最舊的那個**，不從入所介紹的文字猜日期，也不另存一個人工入所日；缺的舊編號由大家在網站上補。

- 舊編號存 D1，指到狗的永久 ID（跟 ADR 0001 同一個 ID），不寫試算表、不新增 Git 提交。
- 跟活動紀錄（ADR 0002）一樣，**任何人都能補、都能刪**，不用通關碼；照 ADR 0004 先選好名字，每次補、刪記進編輯紀錄。
- 換新編號就是再入所（K 2026-10-16），包括轉所和收容所換號；畫面上不標第幾次入所，只列舊編號和最早入所日。
- 網站上所有顯示入所日或在所多久的地方（詳細資訊、分析頁、圖鑑）用同一個算法。

## 後果

- 沒人補舊編號的狗，天數還是照現在的編號算；入所介紹日期比編號早的 21 隻（2026-10-16 清單見 #289）要有人去查出舊編號。
- 有人補錯，排名會跟著錯；要靠編輯紀錄找回。
