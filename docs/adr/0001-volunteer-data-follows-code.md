# 0001 志工自己的資料跟著代號存 D1

日期：2026-10-15（K 決定）

## 背景

「我的常溜」（#155）只存在手機上，換手機就消失，而且是用編號記的，再入所換了編號就對不上。網站很多功能都是在還沒有 D1 和代號的時候做的，所以只能存在手機上。圖鑑開卡（K 2026-10-13）是第一個改成存 D1 的。

代號是 Worker 用名字算出來的（`worker/src/index.js` 的 `walkerCode`），同一個名字永遠得到同一個代號。換手機只要輸入同一個名字，就能找回同一份資料。

## 決定

使用者資料依下面規則分類，新功能要存使用者資料時，先照這條歸類：

- **跟著代號存 D1**：志工自己的選擇和收藏，例如圖鑑開卡、我的常溜。一隻狗一筆，用永久 ID（`v3_dogs.dog_id`）記，不用編號；加入就新增、取消就刪除，兩台手機的改動自然合併。
- **留在手機**：當天的暫存（今天按過的溜了、一起溜的人）、最近一起溜過的名字、畫面偏好、看過說明、管理通關碼。

細節：

- 存在使用者自己設定名字的那個代號（手機代號清單的第一個）底下；讀取時把所有代號的資料合併顯示。
- 還沒設定名字的人，先存在手機上，照樣能用；設定名字後自動合併上傳。舊版只存在手機上的資料也走同一套合併。
- 知道名字就能讀寫那個人的資料，不另外設密碼。這是內部志工工具，收藏不是機密。
- 不寫試算表，不新增 Git 提交。

## 後果

- 換手機、換瀏覽器不會再遺失收藏。
- 別人輸入你的名字，就能看到、也能改你的常溜和開卡。如果以後要存敏感資料，要重新討論身分驗證。
