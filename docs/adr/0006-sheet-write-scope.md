# 0006 網站寫入試算表的範圍

狀態：已採用（K 2026-10-15 #239，取代 2026-10-08「只寫兩欄」；2026-10-16 加常遛狗群）。2026-10-16 從 AGENTS.md 搬來，內容不變。

## 決定

網站只能寫下列幾處，程式在 `apps-script/sheet-write.gs`：

**主清單**
- 「遛狗日期」「誰遛的」兩欄。
- 「備註」欄只追加 `;2026/10/15內容（名字）`：原本空的就不加分號；分號半形、括號全形；月日不補 0。
- 狗清單下方的異動紀錄只新增一列，籠位欄寫下一個「備註N」，編號欄寫 `2026/10/15內容（名字）`。
- 日期由系統帶台灣時間；名字用網站上選好的身分，沒選不能寫；送出前要預覽；寫入前先讀出格子現有內容再接上去；不刪、不改既有文字，寫錯到試算表手動改。

**常遛狗群分頁**（K 2026-10-16，`groups.html` → `/api/groups`）
- 只改狗名格（加狗、移出後往上補、狗名格滿了在群名列上面插一列）和最下面的群名列；數量列不動。

**其他**
- 其他欄位、其他分頁（含已出所）一律不寫入。需要另外記的資料放 repo 或 D1（歸類見 0001），不放試算表。

## 為什麼

試算表是志工和所方共用的主要紀錄，網站寫錯會直接影響現場。所以只開放「只追加、可預覽、可手動復原」的寫入，其他欄位等「以誰為準」定案後再逐項討論（#239）。
