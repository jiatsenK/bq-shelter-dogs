# 0020 獨立管理網站與可控制的志工編輯

狀態：已確認，日期：2026-10-24，K 在管理網站訪談確認範圍並交辦開票。2026-10-25 第 1–3 階段已上線（#564、#565、#566），2026-10-26 第 4 階段上線（#567）；第 5 階段待做（#568）。

為集中桌面管理功能並保留志工網站的簡單操作，採同 repo 的獨立管理 Worker／網址，共用既有 D1、必要 R2 與驗證、資料操作模組；以 Cloudflare Access 驗證單一管理者角色，不將機器用 ADMIN_KEY 交給瀏覽器。相較同 Worker 的 host 分流，多一個部署單位能讓管理站獨立保護與驗收；資料與業務規則仍只有一套。

修訂 ADR 0004 的「不做管理者後台」及固定開放編輯規則：新增管理網站；介紹、照片、休養、活動、固定照顧、出入所紀錄、舊編號各自控制志工可編輯，預設沿用現況。功能顯示另設活動紀錄、資料檢查、更新紀錄三個開關；關閉顯示不刪資料、不停後端。管理者仍能編輯；性別補正為第一版新增的管理者能力，並未開放志工性別編輯。

第一版試算表送入欄位只讀，避免管理網站與 GAS 互蓋；網站獨有資料不寫回試算表。狗的性別以 v3_dogs.sex 為人工維護正本，先核對舊複本差異再統一目前資料的讀取，歷史快照保留。所有新管理修改須驗證欄位、檢查衝突並可靠記錄改前／改後；管理者經驗證身分只在後台可見，志工自行選名字的可信程度維持原定義。實作分期、欄位來源、既有票相依與驗收見 [管理網站計畫](../design/admin-site-plan.md)。

本決策只授權記錄計畫及開票；不代表實作、正式 schema 套用、合併、部署或正式資料修改已獲授權。既有紀錄、志工身分、機器金鑰與核心登記／復原／同步規則維持現況，直到各階段另行驗收。
