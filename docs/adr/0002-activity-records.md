# 0002 活動紀錄與已出所狗卡存 D1

日期：2026-10-15（K 決定）

更新：2026-10-17，K 在 #273 訪談定稿時確認活動整合進資訊頁，手機與桌機皆可查看與編輯，取代下述介面的舊限制；其餘資料與匯入規則不變。

## 背景

每個月有「動保小小兵」（免費親子生命教育體驗課程）和認養會。K 想記錄每場出席的狗，也希望已經出所的狗在圖鑑裡留下紀錄，不要因為被認養就消失。試算表寫入規則不允許新增這類資料，所以要另找地方存。

## 決定

- **活動紀錄存 D1**：日期、類型（固定兩種：動保小小兵、認養會）、出席的狗（永久 ID）。只記出席，不記狗的狀況。不寫試算表，不新增 Git 提交。
- **任何人都能新增、修改、刪除**，不用通關碼，跟溜狗一樣信任大家；D1 留操作紀錄，出事還查得到。
- **手機與電腦皆可使用**：入口整合到「資訊 → 活動紀錄」（#273）；每場標題下直接並列出席的狗，不必點進場次。手機與電腦都能新增、修改、刪除活動與出席名單，先選好身分並留下編輯紀錄（ADR 0004）。狗卡上不顯示活動資訊。
- **舊名單一次性匯入**：名字完全相同就自動接上；其他的先存名字，由 K 之後指定或補建狗卡再接上。
- **已出所狗卡**：圖鑑新增「已出所」名單，每個人都直接收藏，不用開卡、沒有動畫，當作感謝大家的付出。網站開始記錄前就離所的狗，由 K 確認後建只有名字的卡。

## 後果

- 出席和離所紀錄都在 D1，可以算出「去過認養會的狗，多久後被認養」。樣本小，只能當參考。
- 任何人都能刪活動，誤刪要靠操作紀錄還原。
- 已出所狗卡的收藏不算進開卡進度，跟 `docs/adr/0001-volunteer-data-follows-code.md` 的開卡紀錄分開。
