# D1 讀取量原型實測（歷史資料包＋今天紀錄＋記憶體快取）

2026-10-16，分支 `prototype/d1-read-reduction`（丟棄式，不合併）。所有數字都是原型 D1 `bq-shelter-dogs-proto` 回傳的 `meta.rows_read`，用 `wrangler dev --remote` 跑在 Cloudflare 上（不是本機模擬），沒有碰正式 D1。

## 結論

- **現在的 `/api/walks` 每次讀 4,884 列 = 溜狗紀錄 2,442 列 × 2。** `ORDER BY` 要排序，D1 把讀到的列再算一次。`/api/dogs` 每次 687 列。
- **新做法一天 1,014 列（同一台機器一直有快取）～ 26,137 列（每次都是新機器、完全沒快取的最壞情況）。現在的做法同一天 2,522,716 列。** 真實情況在兩者之間，最差也只有現在的 1%。
- 新做法的 4 支 API 輸出和現在逐字元比對完全相同（一天開始前、登記 30 次溜狗之後都比過）。
- `COUNT(*)` 照掃過的列計費（整張表 2,442 列就算 2,442）；`LIMIT n` 只算 n 列，但前提是不用排序或排序剛好走索引，否則整張表照算（見下表）。

## 模擬一天

早上 7 點到晚上 9 點，1,400 次 API 請求（假設：首頁一次讀 dogs＋walks＋rest，所以 dogs／walks／rest 各 450、departures 50），中間登記 30 次溜狗；前一晚重算一次資料包。原始輸出：`2026-10-16-d1-read-prototype-sim.json.txt`。

| | dogs | walks | rest | departures | 合計 |
|---|---:|---:|---:|---:|---:|
| 現在 | 309,150 | 2,212,566 | 450 | 550 | **2,522,716** |
| 新做法，有快取（1 台機器） | 315 | 259 | 387 | 53 | **1,014** |
| 新做法，每次都沒快取（最壞） | 8,300 | 8,287 | 8,577 | 973 | **26,137** |

另加：重算資料包 5,585／次、登記溜狗 60（30 次）。

**跟正式環境對不上的地方**：這個假設下「現在」一天要 252 萬列，但正式量到的是 66–74 萬列。換算回來，正式環境一天大概只有 130–150 次 `/api/walks`，「1,400 次請求」應該包含照片、網頁檔案等不碰 D1 的請求。要拿確切比例得看 Cloudflare 的請求分析；但不管比例多少，新做法每個請求最多讀 1＋1＋今天的列數，量級不變。

## 設計要修正的地方

1. **今天紀錄不要在 SQL 排序**：讀出來在 Worker 裡排，135 列就是 135，不是 270。原型這樣做，輸出仍完全相同。
2. **一定要加 `walk_date` 索引**，不然照日期讀還是整張表 2,442 列。
3. **資料包只在歷史資料真的變了才重算**（一次 5,585 列）。一天重算 100 次就吃掉 56 萬列，等於沒改。要跟 ADR 0008（有改才同步）配合。
4. **過了午夜不必立刻重算**：原型讀「資料包切點之後的所有列」，資料包晚一點重算也不會漏紀錄，只是多讀幾天的列（每天約 30–100 列）。
5. **別用 `COUNT(*)` 當版本號或狀態**：目前 `/api/` 狀態頁的 `compactStatus` 就是三個整表 `COUNT(*)`，每次 2,686 列。
6. **資料包大小**：現在 187 KB（溜狗紀錄佔 165 KB），D1 一列上限 2 MB。照目前每月增加約 80 KB 的速度大約 2 年會到上限，屆時要拆成幾列（例如按月）。
7. 記憶體快取在 Cloudflare 上能活多久、同時有幾台機器，原型量不到；所以上表給「有快取」和「完全沒快取」兩端。

## 怎麼重跑

```
git switch prototype/d1-read-reduction
npx wrangler dev --remote --config wrangler.d1read.jsonc --port 8799
node scripts/prototype/d1-read-sim.mjs
```

原型 D1 的溜狗紀錄是 `proto-seed.sql`（1,221 列）再複製一份往前移 31 天，湊到和正式相近的 2,442 列；另外加了 `proto_walks_date` 索引和 `proto_pack`、`proto_versions` 兩張表，模擬時寫進今天（2026-10-17）30 列。
