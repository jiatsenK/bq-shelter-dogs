## 原因

Apps Script 同一次執行會沿用第一次讀到的表內容。改日期那次執行 A 第二輪等鎖時，改名單那次執行 B 先送了新值；A 拿到鎖後讀到的是自己一開始讀的內容，送出舊值；A 的狗清單同步也送舊名單並清掉待通知，B 就沒得送。Worker 照設計信任 GAS 讀到的值，所以收成新的人工修改、多記一筆「溜了」。問題在 #672 之前就有，#672 只是讓它被看見。
