# 2026-10-20 #420 手機切頁不殘留焦點框

- Agent：Claude Code（雲端）
- 依據：#420
- 原因：switchTab 重繪後一律 focus 頁籤。iOS Safari 點按鈕不給焦點，程式 focus 被當鍵盤焦點，`.tabs button:focus-visible` 顯示橘框。
- 修正：只有焦點原本在頁籤上，或原焦點元素被重繪移除（如返回鈕）時才移到頁籤；鍵盤 Enter／重繪由既有 buildTabs 保留。未動 CSS outline。
- 測試：新增 `tests/tab-focus.cjs`（以 mousedown preventDefault 模擬 iOS 點按不給焦點，先紅後綠）；node 340、網頁 261 全過。
