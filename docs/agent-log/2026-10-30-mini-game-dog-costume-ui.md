# 2026-10-30 小遊戲與狗狗變裝秀介面調整

- Agent：Claude Code（Opus 5.5），分支 `claude/mini-game-dog-costume-ui-8e47b0`
- 依據：K 在對話用 `/impeccable` 要求改小遊戲與狗狗變裝秀的介面（#795 已上線之後）。K 選「沿用病歷夾，加強遊戲感」，不另做視覺世界。

## 做了什麼

- `public/games.html`、`public/css/games.css`、`public/js/games.js`：
  - 選單：遊戲改成封面（隨機一隻變裝狗＋標題、介紹、規則、可出題隻數、最高分＋實心「開始玩」），「更多遊戲・準備中」縮成虛線灰字一條。
  - 遊戲中：題數、10 格答題結果、分數一排；計時條貼在照片上緣、剩 3 秒變紅；答完卸妝（裝飾淡出、照片退回整張），答案寫在照片下緣的綠／紅條；答對停 0.9→1.3 秒、答錯 1.6→2 秒，看得到卸妝。
  - 結算：分數、10 格、最高分、答錯的狗同一張白紙；答錯照片跟著寬度排；「再玩一次」整排寬、在拇指按得到的最下面。
  - 電腦版（≥1100px）改左右兩欄，不再是手機寬度置中。
  - 照片拉近、戴裝飾抽成 `dress()`，遊戲和封面共用。
- `tests/games.cjs`：選單文字改成新結構、封面有裝飾、選單最高分、每題卸妝與 10 格、結算 10 格、電腦版選項在照片右邊且沒有橫向捲動。
- `docs/DESIGN_GUIDE.md` 加「小遊戲」一節記現行規格。

## 例外與要注意的

- 分享截圖（1080×1440）沒改。
- 小遊戲頁仍是獨立頁首加返回，沒有套電腦版五格頁首（DESIGN_GUIDE 電腦版「每一頁同一個頁首」）；要套的話另外討論。
- 封面多讀一張原圖（隨機那隻狗）。
