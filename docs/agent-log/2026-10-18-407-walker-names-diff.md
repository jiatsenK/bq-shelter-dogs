# 2026-10-18 #407 存登記名字只寫有變的

- `rememberWalkerNames`（worker/src/index.js）原本每次讀主清單都把全部名字的 `last_seen` 重寫（約 403 列，加上觸發器再翻倍）。
- 改成：新名字照樣新增；舊名字只在 `last_seen` 不是今天（UTC 日期）時才更新，同一天重讀寫 0 列。最多一天一次全寫，「以前看過」的排序以天為單位仍正確。
- 測試：`worker/test/d1-read.test.mjs` 新增「同一天沒變寫 0 列、多一個新名字寫 1 列、隔天才更新」。
- 依 ADR 0008（只寫差異）。未部署、未碰正式 D1。
