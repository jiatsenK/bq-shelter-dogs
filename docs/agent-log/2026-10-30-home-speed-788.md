## 做了什麼

- `worker/src/index.js` `getDogs`：狗清單、今日溜狗、R2 照片版本號三段同時開始讀，原本一段等一段。錯誤處理照舊：狗清單讀不到回 503，今日溜狗或照片版本號讀不到照樣給狗清單。
- `worker/src/packs.js` `readDogsPacked`：同步時間跟狗清單資料包同時讀。
- `worker/test/dogs-endpoint.test.mjs`：D1 每次讀取都要等 R2 開始列照片，一段等一段就卡住。改前程式會失敗（已確認先紅）。
- `public/index.html`：頁首用 `modulepreload` 列出 main.js 的整個模組圖（40 個檔），瀏覽器讀到 HTML 就一起抓，不用分三輪發現。`scripts/frontend-modules.test.mjs` 新增比對：預載清單要剛好等於 main.js 匯入到的模組。
- `public/css/desk.css`：把 app.css 裡 9 個 `@media (min-width: 1100px)` 區塊（約 47KB）原樣搬出，index.html 用 `media="(min-width: 1100px)"` 載入。手機寬度不符合 media，瀏覽器不會等它才畫畫面；電腦打開時照常先載完再畫，不會閃。
- 文件：`public/js/README.md`、`DESIGN.md`、`docs/DESIGN_GUIDE.md`、`docs/PROJECT_GOALS.md` 寫上 desk.css 與預載清單。

## 例外與要注意的

- CSS 搬到檔尾後，同權重的規則勝負可能改變。逐條比對過電腦版規則與後面同權重、同屬性的規則：唯一可能同時套到同一元素的是 `.desk-on .search` 與 `.page-search .search`，電腦版搜尋框在頁首、不在 `.page-search` 裡（`desk.js` `deskPlaceTabs`），不受影響。其他都是不同元件。
- 縮圖：只有一種縮圖（短邊 300px），尺寸照圖鑑卡片設的，溜狗表只顯示 56px。直接縮小圖鑑會糊，加清單用小縮圖另開 #789。
