# Agent 操作紀錄

AI Agent 對本 repo 做過的實際寫入，供 Claude、Codex 或其他 Agent 接手時確認進度。2026-10-16 之前的紀錄在根目錄的 `AGENT_LOG.md`（已封存）。

## 規則

- 開始修改前，先讀最近幾筆（檔名照日期排序）。
- 寫入 repo 後，在本資料夾新增一個檔案：`YYYY-MM-DD-<分支或主題>.md`，例如 `2026-10-16-fix-edit-log-table.md`。一張 PR 一個檔，同一張 PR 後續的修改寫在同一個檔裡。
- 內容至少包含：日期、Agent、做了什麼、依據（issue／決定）、例外或未完成事項、相關 PR。
- 不改別人的紀錄檔。Git commit／PR 是程式碼變更的正式歷史，這裡記工作脈絡與交接資訊。

一筆一檔，所以兩張 PR 不會改到同一個檔案，也就不會衝突。
