# #390 入所介紹的呈現（2026-10-19 K 確認）

## 本次實作

- 詳細資訊只留「入所介紹」一段，日期與經過直接列出，補充文字接在下面。在所、離所共用；不另設出入所紀錄區、展開入口或原介紹切換。
- 閱讀畫面不逐筆重複編號；對應編號仍保留在既有介紹編輯表單。
- 同日、相同文字只呈現一次；短句若完整出現在另一句開頭且以逗號／分號接補充，保留較完整的一句。日期不同、文字矛盾的資料都保留，不替人決定哪份正確。
- 原介紹開頭明寫 `YYYY年M月D日` 的完整句子可拆成日期與文字排版，其他文字照原樣保留；缺年份、不合理日期不猜。這是閱讀呈現，不產生正式事件，不寫回、不影響入所日。
- 依 #392 盤點，舊 `stays` 的「整修移所」「領養後退養」有出所日時顯示在該段的結束日；其他原因照已確認的入所原因呈現。不推算中間未知的認養、退回日期。
- 無內容不顯示兩段空提示；可編輯時仍保留補介紹入口。
- 在所閱讀時只有原有介紹編輯入口；補登紀錄移至編輯內。切換補登不丟失未存的介紹草稿。離所介紹仍唯讀，既有補登權限維持。

## 保留的資料契約

原介紹全文、`intakeEvents`、`stays`、API、身分要求、編輯紀錄、併發保護及 ADR 0011 入所日算法不變。儲存介紹只送出使用者編輯的原文與既有事件，不把閱讀時拆出的日期自動存成事件。

本次沒有正式資料轉換、批次補日期、雙永久 ID 合併、資料表刪除、部署或合併 PR。這些仍需另行確認對照；本 PR 不應自動關閉涵蓋後續資料工作的 #390。
