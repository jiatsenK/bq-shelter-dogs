# 個性與注意（取代手機狗卡的溜狗紀錄）——設計，還沒寫程式

K 2026-10-10：「我想把手機板 狗卡 溜狗紀錄拿掉，改成狗的個性或是一些行為的紀錄，然後只存在網站這樣…要讓可能不熟的志工也能快速了解。」用 impeccable shape 整理。**狀態：設計已給 K 看，三件事還在等 K 回覆（見最下面）；還沒動工。**

## K 的回答（2026-10-10）

- 最需要知道的：需注意的個性；**若有送養會可以怎麼介紹、之後輸出時可以快速介紹**；**會不會出籠掙脫、不回籠**（新志工帶的時候有心理準備）；好不好牽；對人、對狗；危險與禁忌；喜歡什麼。
- 形式：**標籤＋短句**（上面一排固定標籤點一下就加；下面幾句觀察，新的在上面）。
- 溜狗紀錄：**手機拿掉、電腦留著**（電腦版「最近 30 天」和分析頁照舊）。

## 設計

**給誰看、解決什麼**
- 新志工牽狗出籠前，五秒有個心理準備：會不會衝、會不會掙脫、回不回籠、能不能跟別的狗一起。
- 老志工把觀察記下來，不用再擠進試算表備註（現在 122 隻有 92 隻有備註，洗澡、醫療、搬籠、「不親狗、護食」、咬了誰都混在同一格）。
- 之後送養會或輸出報表時可以直接拿來介紹。

**畫面（手機詳細資訊）**
- 位置往上移：名字和天數下面、「同籠的狗」上面（出籠前就要看）。
- 第一排「適合誰帶」三選一：新手可以／要有經驗／要兩個人。
- 第二排標籤：點一下加上、再點一下拿掉，不用打字。
- 「最近的觀察」：一句話一筆，新的在上面，顯示日期和誰寫的；預設 3 筆，其餘收起來。
- 最下面「一句話介紹」：給送養會和輸出用的正面介紹，60 字以內。
- 溜狗紀錄從手機狗卡拿掉。

**標籤（先給一套，等 K 增刪）**

| 類別 | 標籤 |
|---|---|
| 出籠／回籠 | 出籠會衝、會掙脫胸背、不肯回籠、怕套牽繩 |
| 牽起來 | 好牽、力氣大、會暴衝、不太肯走 |
| 對人 | 親人、慢熟怕生、會撲人、會咬人 |
| 對狗 | 親狗、挑狗、不親狗 |
| 要注意 | 護食、怕車怕聲音、會亂撿東西吃、不能摸特定部位 |
| 喜歡 | 喜歡摸摸、喜歡零食、喜歡玩具、喜歡跑 |

- 顏色照現有規則（紅黃綠只給天數和警示）：「要注意」類、會咬人、會掙脫、不肯回籠用紅框，其他中性。
- 溜狗表的狗卡第一層只放紅框那幾種，最多兩個。
- 標籤表放 `js/site-config.js`（其他收容所可以換自己的）。

**誰能改、存哪裡**
- 所有人都能加，不用通關碼（K：不管控，只要有紀錄可以恢復）。
- 每次加、刪都記進資料庫的 `changes`（誰、什麼時候、改了什麼），之後可以還原。
- 只存在網站的資料庫（D1），不寫試算表；試算表備註照舊顯示在原位。這是資料庫第一個真正用上的地方。
- 預覽版沒有接資料庫，只能看、不能存。

**這次不做**
- 不自動把試算表備註轉成標籤（之後可以做「備註有『不親狗』就建議這個標籤」）。
- 電腦版補資料表格先不加這一欄。
- 輸出報表等管理頁面那一步。

## 等 K 回覆

1. 標籤表要增刪哪些（特別是「出籠／回籠」「要注意」）。
2. 「適合誰帶」三選一可以嗎，還是不分級只用標籤。
3. 觀察要不要顯示是誰寫的（顯示的話用他在網站選的名字，沒選就「沒留名字」）。
