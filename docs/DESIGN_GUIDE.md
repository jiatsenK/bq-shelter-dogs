# 視覺風格指引

以 [`design/reference-preview.webp`](design/reference-preview.webp) 為準：淺藍白底、白色圓角卡片、方形圓角照片、天數色標徽章。
參考圖第二頁的「狗狗詳細卡片」與第四頁以外的分頁安排僅供風格參考，**功能範圍以 [`PROJECT_GOALS.md`](PROJECT_GOALS.md) 為準**（三分頁含「依籠位」）。#28 起點狗卡會開詳細資訊（從下方滑出的面板，不是另一頁）。

實作畫面：[`design/screenshot-due.png`](design/screenshot-due.png)、[`design/screenshot-special.png`](design/screenshot-special.png)

## 色票

所有顏色都定義在 `index.html` 的 `:root` CSS 變數，改色只改這裡。

| 用途 | 變數 | 色碼 |
|---|---|---|
| 頁面底色 | `--bg` | `#EEF4FB` |
| 卡片／頁首 | `--surface` | `#FFFFFF` |
| 搜尋框底色 | `--surface-soft` | `#F4F7FB` |
| 主要文字（深藍） | `--ink` | `#1E2A44` |
| 次要文字 | `--ink-soft` | `#6B7890` |
| 主色（Logo、選中分頁、同籠標籤圖示） | `--primary` | `#2F7BEA` |
| 主色淺底（同籠標籤、預設照片底） | `--primary-soft` | `#E7F0FD` |

### 天數色標（字色／底色）

| 狀態 | 條件 | 字色 | 底色 |
|---|---|---|---|
| 綠：安全 | 0～6 天 | `#2E8B45` | `#DDF4E2` |
| 黃：注意 | 第 7～29 天 | `#A86400` | `#FFF0C2` |
| 紅：緊急 | 第 30 天起 | `#D93036` | `#FDE7E7` |
| 灰：無紀錄 | 沒有遛狗日期 | `#7A8599` | `#EEF1F5` |

天數與顏色一定一起出現：卡片上是彩色天數文字（例：「45 天前」紅字），詳細資訊頂端是徽章（紅底紅字）。

## 字體與字級

- 字體：Noto Sans TC（Google Fonts），備援 PingFang TC／微軟正黑體。
- 標題「板收遛狗」22px / 900
- 犬名 18px / 700
- 天數徽章 14px / 700
- 分頁標籤 14px（數字 12px）
- 籠位｜編號、警示備註 13.5px；詳細資訊內文 14px
- 搜尋框 16px（避免 iOS 聚焦時自動放大）

## 元件

- **頁首**：白底、固定在頂端；藍色腳掌 Logo＋標題，下方日期「9月24日 (四)」與右側「最後更新 HH:MM」。
- **分頁**：三格等寬圓角按鈕（12px 圓角），標籤上排、隻數下排。選中為藍底白字。
- **卡片**（#28 高密度版，照 K 給的參考清單圖，手機一畫面約 7 隻）：白底、14px 圓角、淡陰影 `0 2px 10px rgba(30,42,68,.06)`、內距約 6px、卡片間距 6px。整張卡片可點，開啟詳細資訊。
  - 左：64×52 照片，10px 圓角；抓不到照片時顯示淺藍底＋藍色腳掌。
  - 中：犬名（18px 粗體；性別符號預留在犬名後；有一般備註時犬名旁一個橘色備註小圖示）→「編號 | 籠位」。
  - 右：小字「上次遛狗」＋彩色天數文字（17px 粗體，綠／黃／紅照天數色標；尚無紀錄灰字）→ 淡灰右箭頭。
  - 有命中警示關鍵字時，下方多一行警示備註。
- **警示備註**：備註含勿溜（勿遛、勿蹓）、不要、攻擊、不親狗、不親任一個，就把備註原文放在卡片第一層：紅色外框、極淡紅底、三角警示圖示、紅色粗體，命中字眼加底線。不另外產生固定文字的徽章。所有分頁、搜尋、籠位共用同一張卡片（`dogCard`）。
- **詳細資訊**：淺藍底面板，手機從下方滑出、桌機置中（最寬 480px）。上方白卡：84px 照片、天數徽章、犬名、籠位｜編號、右上圓形關閉鈕。下面三張白卡：備註（文件圖示）／可以一起溜的狗（人群圖示，64px 照片＋犬名格狀排列）／狗卡資訊（證件圖示）。
- **近期已遛**：區塊標題前加綠色腳掌。
- **依籠位**：白色圓角籠位按鈕，點入後顯示「‹ 所有籠位」返回。

## 原則

- 唯讀：除了搜尋框，不放任何輸入框、勾選框、編輯圖示。
- 手機單欄、最大寬度 480px，字夠大、點擊區夠大。
- 圖示一律用頁內 SVG（`<symbol>`），不額外載入圖示庫。
