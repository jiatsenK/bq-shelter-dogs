# 視覺風格指引

以 [`design/reference-preview.webp`](design/reference-preview.webp) 為準：淺藍白底、白色圓角卡片、方形圓角照片、天數色標徽章。
參考圖第二頁的「狗狗詳細卡片」與第四頁以外的分頁安排僅供風格參考，**功能範圍以 [`PROJECT_GOALS.md`](PROJECT_GOALS.md) 為準**（四分頁含「依籠位」、不做詳情頁）。

實作畫面：[`design/screenshot-due.png`](design/screenshot-due.png)、[`design/screenshot-special.png`](design/screenshot-special.png)

## 色票

所有顏色都定義在 `index.html` 的 `:root` CSS 變數，改色只改這裡。

| 用途 | 變數 | 色碼 |
|---|---|---|
| 頁面底色 | `--bg` | `#EEF4FB` |
| 卡片／頁首 | `--surface` | `#FFFFFF` |
| 搜尋框底色 | `--surface-soft` | `#F4F7FB` |
| 主要文字（深藍） | `--ink` | `#1E2A44` |
| 次要文字 | `--ink-soft` | `#6B7890` |
| 主色（Logo、選中分頁、同籠標籤圖示） | `--primary` | `#2F7BEA` |
| 主色淺底（同籠標籤、預設照片底） | `--primary-soft` | `#E7F0FD` |
| 特殊狀況選中分頁 | `--danger` | `#E5484D` |

### 天數色標（字色／底色）

| 狀態 | 條件 | 字色 | 底色 |
|---|---|---|---|
| 綠：安全 | 7 天內 | `#2E8B45` | `#DDF4E2` |
| 黃：注意 | 超過 7 天 | `#A86400` | `#FFF0C2` |
| 紅：緊急 | 超過 30 天 | `#D93036` | `#FDE7E7` |
| 灰：無紀錄 | 沒有遛狗日期 | `#7A8599` | `#EEF1F5` |

天數與顏色一定放在同一個徽章裡（例：「45 天前」紅底紅字）。

## 字體與字級

- 字體：Noto Sans TC（Google Fonts），備援 PingFang TC／微軟正黑體。
- 標題「板收遛狗」22px / 900
- 犬名 18px / 700
- 天數徽章 14px / 700
- 分頁標籤 14px（數字 12px）
- 籠位｜編號、備註、同籠 13–13.5px
- 搜尋框 16px（避免 iOS 聚焦時自動放大）

## 元件

- **頁首**：白底、固定在頂端；藍色腳掌 Logo＋標題，下方日期「9月24日 (四)」與右側「最後更新 HH:MM」。
- **分頁**：四格等寬圓角按鈕（12px 圓角），標籤上排、隻數下排。選中為藍底白字，「特殊狀況」選中為紅底。
- **卡片**：白底、18px 圓角、淡陰影 `0 2px 10px rgba(30,42,68,.06)`、內距 12px、卡片間距 12px。
  - 左：84×84 照片，14px 圓角；抓不到照片時顯示淺藍底＋藍色腳掌。
  - 右：天數徽章 → 犬名 → 「籠位 | 編號」 → 備註標籤（淡紅底＋三角警示圖示，完整顯示不截行，規格要求卡片內看得完）→ 同籠標籤（淡藍底＋人群圖示「可一起遛：…」）→ 介紹文字（最多 3 行）。
  - 卡片不放右箭頭，因為沒有詳情頁，避免看起來可以點。
- **特殊狀況**：頂端淡紅提示框說明排除原因；卡片徽章改為紅色「! 關鍵字」並附「備註含關鍵字，請確認」，備註中所有命中的關鍵字都以紅色粗體標出。所有分頁、搜尋、籠位共用同一張卡片，特殊狀況的狗在哪裡出現都看得出來。
- **近期已遛**：區塊標題前加綠色腳掌。
- **依籠位**：白色圓角籠位按鈕，點入後顯示「‹ 所有籠位」返回。

## 原則

- 唯讀：除了搜尋框，不放任何輸入框、勾選框、編輯圖示。
- 手機單欄、最大寬度 480px，字夠大、點擊區夠大。
- 圖示一律用頁內 SVG（`<symbol>`），不額外載入圖示庫。
