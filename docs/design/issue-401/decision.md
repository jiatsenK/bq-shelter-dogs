# #401 決定：天數只有字＋現行位置的溜了按鈕

日期：2026-10-20。K 操作 `prototype.html`（六版）後先選「C 窄籤＋1」，比較 B／C 並排截圖後改定「B 只有字＋1 現行框」（理由：戶外大太陽下整個數字上色比 6px 色條好認，顏色仍在天數格、與現行接近）。前提：不要跟現行網站差太多，大家已經在用。

## 選定

- **天數 B 只有字**：天數格不上底色，數字本身上色（黃字 3～4 天、紅字 5 天起）；0～2 天、今天是灰字。取代現行整塊實心色籤。
- **溜了按鈕 1**：位置、尺寸、按法維持現行。未登記是淡灰底細框黑字（不再是白底綠框）；已溜是淡綠底＋✓，**不加外框**（K：已溜框框好醜）。
- **綠色只代表已溜**：照片底、籠位圖釘、0～2 天不再用綠。
- **今天誰溜過**：名字下一行字。別人溜過寫「小美 溜過了」（灰），自己登記寫「✓ 你和小美溜過了」（綠）；別人溜過仍顯示一般「溜了」，不另做按鈕。
- **失敗**：按鈕淡紅底「重送」，名字下寫「沒寫進試算表，再按一次」。名單被別人改過、不能取消時，「✓ 已溜」只是字、不是按鈕。
