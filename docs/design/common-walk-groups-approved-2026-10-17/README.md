## 設計依據

密集斜照片卡、淡灰綠籠號窄邊、下緣姓名、每群「＋」空白卡、左右前後景切群。日期離開卡片，移至群名下用白話說明；登記以整群為主，例外在原卡片上排除。

詳見 [實作規格](../mobile-ui-implementation-spec.md) 與 [決策交接](../mobile-home-and-groups-decisions.md)。較早的無照片、圓泡泡、深綠籠號、卡片日期版本都不是定版。

- 2026-10-17 快照：新十 10 隻；愛心推車組 2 隻（當時並列最小群之一），全量共 11 個非空群。這些不是固定的產品數量。

- `approved-fragment.html` 是供 Codex 對話顯示的 HTML 片段，圖示由對話宿主提供，不是獨立站台。原型內兩群、固定日期與前端登記提示僅為示意；不能直接接上正式資料或當作已完成全部功能。
- 正式版要依台灣日期計算文字，使用全量群及現有讀寫介面。未知、失敗、休養和沒有紀錄均不可冒稱已溜；同日只代表狗各自有紀錄，不推論是同一次或同一人整群出勤。
