## 模組與測試介面

延用 #396 的 `createWalkRegistration`：登記／追加／復原回應、今日溜狗紀錄與重新讀取名單共用狀態套用規則。`state` 分開回傳今天有人溜過、自己已登記、可否復原；`today` 供我溜過使用同一份已確認現況。

資料讀取開始時取得 `beginRead`，回應交給 `receiveToday` 或 `receiveNames`，處理逆序回應與本頁較新的修改。後者只有名字，不推測新日期。同步正本比暫時紀錄新時採用正本；本機復原證據仍須核對正本現況。

HTTP、本機儲存、重畫由 app 的 adapter 提供；不新增來源抽象、不改 Worker、GAS 或 D1 結構。ADR 0001、0005、0006、0007 繼續適用。

測試透過上述共用介面，涵蓋不同抵達順序、舊輪詢、部分成功、名字移除、跨日、多人名單與復原衝突；保留狗卡／詳細資訊／狗群整合檢查。
