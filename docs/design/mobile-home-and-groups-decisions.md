## 常遛狗群：2026-10-17 已定版

K 在本輪最後的「好，這樣訂版」確認的是白話溜過時間版本；不是舊圓泡泡、無照片或每張卡都放日期的版本。

- 密集、交錯排列的斜照片卡，姓名在下緣；十隻與兩隻採相同卡片規則，少數群不放大填滿。
- 籠號在卡片右上方的獨立窄邊，不疊住照片；淡灰綠底、深灰綠字，已撤回先前的深綠實心底與白字。
- 卡片不常駐顯示溜過日期。群名下用白話說明：同日如「10 隻今天都溜過」；不同日如「捷運站昨天溜過；甜甜前天溜過」。個別時間仍可查閱，不再塞回卡片。
- 左右滑動換整群；其他群以縮小、較淡的照片群浮在後方，讓人知道可滑動。後景不顯示新增卡。觸碰可放大，尊重減少動態效果。
- 每群都有一張同形狀的空白「＋」卡，用來加入狗；頁面另保留「＋狗群」。
- 主要動作是「整群溜了 · N 隻」。少數狗這次沒溜時，點「有狗沒溜」，在卡片上排除，再按「登記其餘 N 隻」；可取消、恢復，零隻不能登記。只留一隻即可完成單隻登記，不另放同權重的單隻按鈕。
- 沒有重複的頁面標題或底下重複姓名；保留原站配色、主頁與導覽的定版。

定版圖、互動片段與來源說明已保存於 [定版參考目錄](common-walk-groups-approved-2026-10-17/README.md)。互動片段只示範兩群、本機狀態與假登記，不是可直接部署的正式程式。實作需補齊全量群、真實讀寫與錯誤處理。

### 延續的使用場景與必要能力

志工站在現場，用手機找狗與牽狗，需要迅速知道「有誰、幾天沒溜、在哪、跟哪些狗同群」，減少來回切表。

- 狗名與籠位直接可讀；上次溜以最新白話摘要與個別查閱呈現，位置能快速查看。
- 牽完／溜完後以整群登記為主；這次只有部分狗一起溜時，快速排除未溜的狗；仍可只登記一隻。
- 同一處提供「＋狗群」。
- 盡量在手機可見範圍內完成高頻操作；K 明確說不要靠一直往下滑或切表。全量群的呈現方式仍須解決，不能只把兩個範例塞滿一頁就宣稱完成。
- 群關係清楚，排版自然、有活力，但原站配色保持一致。
- 常遛狗群名稱沿用志工習慣，不改叫「家」。既有群成員不等於本次實際一起溜的名單，也不代表已完成或自動推論相容性。
