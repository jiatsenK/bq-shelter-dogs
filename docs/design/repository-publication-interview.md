# Repository 公開前整理訪談

日期：2026-10-22。依據：[Security Issue #493](https://github.com/jiatsenK/bq-shelter-dogs/issues/493) 與 K 在本次 grill-with-docs 訪談的回答。狀態：訪談中，尚非實作規格。

## 已確認

- 整理目前的私人 Repository，目標是轉為 Public，降低 GitHub Actions 執行分鐘數成本。公開原始碼不得暴露實際收容所、狗狗資料、志工身分或正式網站位置。
- 保留現有部署與同步功能；正式 Worker、D1、R2 的名稱及網站位置維持既有值。公開內容與正式執行時所需的私有設定必須分開處理。
- Q1：公開驗收涵蓋程式、Git 歷史、Issue／PR、圖片、部署紀錄與日誌；不得含真實資料或可拼回正式網址的設定。外部既有連結、他人副本及搜尋結果無法保證消失，應明列此限制。
- Q2：可接受清理歷史造成部分 commit SHA、舊連結及 PR 差異失效；先保留受控完整備份，盡量保留去識別後的程式歷史。實際改寫、刪除或更名前須另列具體操作清單並確認。
- Q3：維持志工完全免登入，不增加首次受邀啟用或裝置辨識。K 已接受知道正式網址的人仍可能依現有功能查看資料、選擇名字或修改資料的殘餘風險；本次公開整理不以「只有志工能讀寫」作承諾。
- 公開 GitHub 的去識別、後端輸入與寫入量限制、防濫用及受控復原仍為整理要求；機器間的管理、部署、通知及試算表寫回金鑰保留，不因志工免登入而移除。具體措施尚待核對現況及成本後定案。

## 正在釐清

- Q4：K 回覆「先維持這樣」。暫按保留現有名稱、不先更名理解；是否也保留公開品牌文案尚未確認，不能解讀為撤回 Q1 的去識別要求。正式 Worker、D1、R2 及網址仍維持既有值。
- Q5：K 詢問如何查看私有紀錄，尚未接受具體方案。目前沒有為本任務建立私有日誌服務。
- 可先規劃保留 GitHub Actions 的去識別技術日誌，讓執行階段、檔案行號與錯誤代碼仍可供除錯；網站執行錯誤可由 Cloudflare 帳號內的 Worker 日誌查詢，但須先確認是否啟用。Actions runner 的部署／同步錯誤不會自動進入 Worker 日誌。是否另存完整私有診斷紀錄、如何取得預覽網址，仍待決定。
- 原 repo 的各類 GitHub 紀錄是否可實際清理到 Q1 標準，以及所需操作與平台限制。
- Cloudflare 防濫用功能、適用網址、方案與成本尚未完成選型；不預設採用會增加志工驗證操作的功能。
