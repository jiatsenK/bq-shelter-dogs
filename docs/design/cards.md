### Overview

**Creative North Star: "板收明星隊球員卡"**

收容所的狗是一支職棒球隊，這一頁是一套球員卡：溜過才拿得到，撕、翻、收。地是深夜球場：深藍和淺一階的藍交替成 7.5vw 寬的直條草皮紋，中間淡淡一圈投手丘線。主角是一包燙金卡包，撕開後五張卡扇形攤開；卡面是白邊（或銀、金、雷射框）、滿版照片、隊色色帶、斜體粗黑狗名、Anton 背號。往下換成白底的年度獎項（金框獎座），再往下回到最深的藍，是一頁一頁的圖鑑卡套。

這是展示用的，要熱鬧、會反光、會動，跟志工版的安靜實用刻意不同；但動作只用卡片本身的語法（發、翻、傾斜、流光），系統設定減少動態時直接攤開、不傾斜、不流光。

**Key Characteristics:**
- 深藍直條球場是地，燙金是唯一的亮面材料
- 卡片等級看在所多久：普卡白框、銀卡、金卡、雷射卡，等越久框越亮
- 隊色看犬舍：色帶、沒照片時的底、圖鑑每頁的色點都用同一個隊色
- 數字一律 Anton，中文一律 Noto Sans TC 900／700
- 卡片是真的物件：有厚影、會翻面、跟著滑鼠傾斜反光

### Colors

深夜藍的地、粉筆白的卡、燙金的亮點，加一組按犬舍分的隊色；紅色只在獎項緞帶和卡包上的「撕開」。

#### Primary
- **燙金**（`--gold` #E8B400）：大標「板橋動物之家」、圖鑑進度條、「再開一包」、獎項數字、卡背的標籤字和球齡數字、卡背金色內框、徽章的金圈。在深藍上 7.3:1。
- **亮金**（`--gold-hi` #FFD95A）：「NEW」標籤、重複張數 ×N 的小牌、「再開一包」滑過、全頁的焦點框。
- **金箔漸層**（卡包、金卡框、獎座外框；#8A6400／#9A7200 到 #FFF2BA 之間 115°或 135° 的多段漸層）：只給「有收藏價值」的實體：卡包、金卡、獎座。卡包的漸層 240% 寬、4.5 秒來回流動。

#### Secondary
- **隊色**（寫在 `public/js/site-config.js` 的 `zones`，用 `--team` 傳進元件）：新犬舍 #1F5C9E、舊犬舍 #0F6B6B、幼母犬舍 #875700、C區 #2F7A45、住院區 #6E4A9E、其他 #55605B（K 2026-10-30：卡面不用球隊說法，寫區名）。全部是中明度（OKLCH 約 47–52%），上面放粉筆白字都在 4.7:1 以上。用在卡面色帶、照片沒載到前的底、沒照片時的補位底、圖鑑每頁標題前的色點。
- **等級框**：普卡是粉筆白；銀卡 #8E97A1–#F2F4F6 的 135° 金屬漸層；金卡用金箔漸層；雷射卡是 65° 細白斜紋疊在粉紅、黃、薄荷、藍、紫的 125° 彩虹上，彩虹位置跟著滑鼠走。

#### Tertiary
- **緞帶紅**（`--red` #C41E33）：年度獎項左上的緞帶、卡包上的「撕開」，粉筆白字 5.3:1。

#### Neutral
- **球場藍**（`--navy` #0B2A5B）／**草皮淺藍**（`--navy-2` #0D3068）：第一屏的直條紋；`--navy` 也是卡背、獎座內頁、徽章字的底。
- **夜空藍**（`--navy-deep` #071B3D）：html 底色、圖鑑整段的底；圖鑑每一頁是再亮一點的 #0E2147。
- **粉筆白**（`--chalk` #F4F4F0）：卡面框、深底上的主要字、獎項整段的底、已收到的卡套、隊伍切換選中的底。
- **燈光藍**（`--sky` #C6D2E8）／**看台藍**（`--sky-dim` #8FA3C8）：深底上的次要字和說明；看台藍也是圖鑑進度分母、還沒收到的背號（在夜空藍上 6.7:1）。半透明的燈光藍（.06–.5）是卡套、分隔線、外框。
- **墨藍**（`--ink` #0A1428）／**灰墨藍**（`--ink-soft` #46506B）：白底、金底上的字。

#### Named Rules
**The 金是收藏 Rule.** 金箔漸層只給卡包、金卡和獎座；平面的 `--gold` 是重點字和主要按鈕。不要拿金色當一般裝飾。

**The 隊色是犬舍 Rule.** 隊色只表示「哪一隊（哪個犬舍）」，同一隊在色帶、補位底、圖鑑色點必須同色；新隊色要中明度，上面的粉筆白字 4.5:1 以上。

**The 紅色是獎 Rule.** 紅只給獎項緞帶和「撕開」，不要拿來表示其他狀態。

### Typography

**Display Font:** Anton（Google Fonts，400），後備 Noto Sans TC
**Body Font:** Noto Sans TC（Google Fonts，500／700／900），後備蘋方、微軟正黑體
**Label/Mono Font:** 數字都用 Anton，不另用等寬字

**Character:** 窄高的 Anton 像球衣背號和計分板，只拿來寫數字和拉丁字的隊名；中文用 Noto Sans TC 的 900 撐出球員卡的粗黑感。全站只有這一頁載網路字型；志工版照舊用系統字。

#### Hierarchy
- **Display**（Anton 400, clamp(44px, 5vw, 76px), 行高 .95, 字距 .01em）：左上「板橋動物之家 2026」（K 2026-10-30 改，原本 BQ ALL-STARS），中文用 Noto Sans TC 900 燙金、年份 Anton 粉筆白；左邊徽章寫「板收 圖鑑」。
- **背號與計數**（Anton 400）：卡面背號（卡寬 22%）、圖鑑進度（40px）、獎項數字（64px）、圖鑑頁數（22px）、卡套背號（26px）、NEW、×N。
- **Headline**（Noto Sans TC 900, clamp(32px, 3.2vw, 46px), 行高 1.1, 字距 .06em）：「年度獎項」「圖鑑」段落標題。
- **狗名**（900, 卡寬 12%, 行高 1.05, `skewX(-8deg)`）：卡面的斜體粗黑狗名。斜體是用 skew 做的，Noto Sans TC 沒有斜體。
- **Title**（900；獎座狗名 28px、緞帶 22px 字距 .15em、圖鑑每頁隊名 20px）。
- **Body**（500, 14–16px）：卡背「收容所的話」行高 1.65。
- **Label**（700, 13–14px, 字距 .1–.25em）：「志工版溜狗表」「已收」「點卡包撕開」「點卡片翻到背面」這類短句，靠拉開字距像印在球場看板上。卡面色帶 900、字距 .14em。

#### Named Rules
**The 數字用背號 Rule.** 背號、張數、天數、年數這些要被看見的數字用 Anton；中文和夾在中文裡的小數字用 Noto Sans TC（卡背資料列用 `tabular-nums`）。

**The 卡片等比 Rule.** 卡片上的字和間距都是卡寬（`--cw`）的比例，所以手上、大卡、獎座、卡套四種尺寸是同一張卡縮放。

### Layout

三段直向疊：第一屏球場（至少 100svh，頁首、卡包桌、下方提示三列）→ 白底年度獎項 → 夜空藍圖鑑。段落左右 48px、上下 96px；段落標題在左、說明在標題下面，圖例等操作靠右、跟說明同一條基線，下方 40px。卡寬 `--cw` 是 clamp(150px, 16.5vw, 248px)，卡包是卡寬 1.2 × 1.68 倍（最大約 298×417px）、卡片 1 × 1.4。

撕開後五張扇形：每張往兩側平移約一張卡寬、離中間每一張下沉 26px、旋轉 4°。年度獎項三欄、間距 40px。圖鑑每隊一頁、頁與頁 28px，卡套至少 96px 寬自動排滿、間距 12px／10px。

只為電腦寬螢幕設計；900px 以下（手機打開分享連結）卡寬改 clamp(116px, 32vw, 190px)、扇形擠成 10px／3°、獎項一欄、卡套固定四欄、左右 18px，只求不壞。

### Elevation & Depth

立體，而且是真的物件感：卡包、卡片、獎座都浮在桌面上有厚影；平面的底（球場、圖鑑頁）只用細 inset 線分層。

#### Shadow Vocabulary
- **卡片**（`box-shadow: 0 24px 50px rgba(0, 0, 0, .5)`）：手上的卡、大卡的正反面。
- **卡包**（`filter: drop-shadow(0 34px 40px rgba(0, 0, 0, .5))`）：用 drop-shadow 是因為卡包有鋸齒遮罩。
- **獎座**（`box-shadow: 0 22px 44px rgba(11, 42, 91, .28)`）：白底上用帶藍的影。
- **已收到的卡套**（`box-shadow: 0 6px 14px rgba(0, 0, 0, .35)`）：插在卡套裡的卡比空卡套高一層。
- **內框**：徽章和卡包圓徽用多圈 inset 線（金、白、藍）；卡背 `inset 0 0 0 calc(var(--cw) * .018) var(--gold)`；圖鑑頁 1px、空卡套 1px 半透明燈光藍。
- **背號字影**（`text-shadow: 0 2px 0 rgba(0, 0, 0, .35), 0 0 12px rgba(0, 0, 0, .25)`）：讓白色背號壓在任何照片上都讀得到。

#### Named Rules
**The 物件才浮 Rule.** 有影子的只有拿得起來的東西：卡包、卡、獎座、收到的卡。球場、段落、圖鑑頁不加外陰影。

**The 雷射不霧照片 Rule.** 雷射彩虹層（`mix-blend-mode: color-dodge`）在照片區只留約 7%，到框和名字那一塊才滿；滑鼠亮點（`screen` 的白色光暈）是另一層，照樣掃過照片。

### Shapes

卡的形：卡片圓角是卡寬 4%（約 6–10px），卡套 5px、卡套裡的照片 2px；獎座外框 12px、內頁 4px；圖鑑頁 6px；按鈕、隊伍切換、輸入框 3px。卡包上下緣是 12px 一齒的鋸齒封口，撕開時上緣沿 13% 的虛線撕成不規則鋸齒。唯一的圓：左上徽章是膠囊（41px 圓角）配三圈 inset 線，像球衣臂章；卡包上的圓徽；大卡的關閉鈕。

### Components

#### 卡包（Signature Component）
金箔漸層、鋸齒封口、中間藍底金圈的腳掌圓徽、「板收明星隊」900 墨字、下方紅底「撕開」。平常流光；滑過時上浮 10px、左傾 1.5°。點了上緣那條沿虛線撕下、往左上飛走（.6s），卡包往下掉出畫面（.8s），卡片從原位升起攤開。

#### 球員卡（Signature Component）
- **正面：** 等級框（框的寬度是卡寬 4.5%）包著照片；照片左上 Anton 背號、右上亮金「NEW」（新收到的才有）；下方隊色色帶寫隊名和等級；再下面斜體粗黑狗名、灰墨藍「籠位 新B04」和性別。
- **背面：** 球場藍底、金色內框；狗名＋金色背號、看台藍的卡號（BQ26・001/總數・隊名）、上下細線夾住的三列資料（入所、在所、本月出門），金色標籤；收容所的話；最下面等級說明。
- **沒照片：** 隊色底加淡斜紋和一隻狗的剪影，大大的淡背號，中間「照片補拍中」。
- **互動：** 點了繞 Y 軸翻面（.7s）。滑鼠在上面時上浮 26px、放大 1.07、跟著游標傾斜（最多約 13°／11°），雷射層和亮點跟著游標位置移動。剛收到的卡發完後亮一下（1.4s）。
- **Focus：** 卡面外加 4px 亮金框。

#### 年度獎項（獎座）
12px 金箔外框、球場藍內頁；1:1 照片、左上紅緞帶寫獎名；下面粉筆白 28px 狗名、燈光藍說明、右邊金色 Anton 大數字加單位；最下一行看台藍小字是獎座的卡號。滑過時整座上浮 6px、微傾，照片放大 1.04。點照片開大卡。

#### 圖鑑（卡套頁）
每隊一頁，#0E2147 底、6px 圓角、1px 內框；標題前一顆隊色小方塊，右邊 Anton「拿到 / 總數」；段落標題右邊一排圖例。卡套三種、照片都是 1:1：拿到的是等級框小卡（照片＋名字），滑過上浮 4px；溜過還沒撕的是球場藍底、2px 金框的卡背，金色腳掌＋「待開」，點了回卡包；沒溜過的是半透明空卡套裡灰階、壓暗到 55% 的照片，滑過稍微亮起來，點了開灰卡。卡套上有一道 160° 的反光。

#### 已出所（#271）
圖鑑下面另一段「已出所」，標題下一行寫幾隻、「謝謝大家陪過牠們，每個人都直接收藏」。每個人（包括新志工）都直接收藏：卡套全是拿到的樣子（普卡白框），沒有待開、灰卡、卡包和發卡動畫，不算進上面的開卡進度。區色用「其他」。大卡正面色帶寫「已出所」和離所原因（被認養／當小天使了／離開收容所／原因待確認），沒有背號；背面四列：在所期間（入所日 – 離所日）、在所多久、溜過幾天、出席活動幾次。只有名字的卡用沒照片的補位。

#### 灰卡（還沒拿到）
卡框換成 #B9BFC9、色帶 #6B7385、照片灰階，沒有雷射層；等級寫「還沒拿到」，背面最後一行「溜過○○就拿得到這張卡」。

#### Badges
- **新卡張數：** 卡包右上角外面、紅底粉筆白 900 15px、轉 6°、有厚影；撕開後淡出。

#### Focus
全頁統一 3px 亮金外框、離 3px。

#### Navigation
沒有導覽列。右上只有燈光藍 14px「← 溜狗表」（底下 1px 半透明線，滑過變粉筆白）和圖鑑進度（「已拿到」＋Anton 的 N/總數＋4px 金色進度條），點進度跳到圖鑑。頁尾再放一次回溜狗表的連結。

#### 大卡
86% 深藍遮罩，卡寬 min(340px, 72vw, 52vh)，從下方 30px、0.94 倍彈出（.45s）；可翻面、可傾斜，下面一行看台藍「點卡片翻面・Esc 關閉」。

#### 動作
- **主緩動**（`--ease`: `cubic-bezier(.2, .9, .2, 1)`）：發牌、翻面、進度條、滑過。
- **發牌：** 每張間隔 120ms（第一張 140ms 後），.9s 從 0.62 倍升到扇形位置。
- **減少動態：** 卡包不流光、不撕、不發牌、不傾斜，卡片直接在扇形位置；翻面、大卡也不做過場。

### Do's and Don'ts

#### Do:
- **Do** 改這一頁的顏色、字級時改 `public/css/cards.css` 的 `:root`；隊色和等級改 `public/js/cards.js` 的 `BQ_TEAMS`、`BQ_TIERS`，再用 `/impeccable document` 更新這一段。
- **Do** 新增的元件放在球場藍、夜空藍或粉筆白其中一種底上；深底上的次要字用燈光藍或看台藍。
- **Do** 新的隊色取中明度（OKLCH 約 47–52%），量過上面粉筆白字 4.5:1 以上。
- **Do** 卡片的新尺寸用改 `--cw` 的方式縮放，不要另外寫一套字級。
- **Do** 新的互動沿用卡片的發、翻、傾斜、流光，並在減少動態時直接到最後的樣子。

#### Don't:
- **Don't** 把這一段的深藍、燙金、Anton、網路字型、膠囊徽章帶進 `public/index.html`／`public/css/app.css`；志工版的規則（綠色等於最近溜過、只有警訊是實心、直角檔案）也不管這一頁的隊色和卡片。
- **Don't** 讓這一頁變回認養網站的「標題＋一排排圓角照片卡」；照片格只出現在圖鑑的卡套裡。
- **Don't** 做成上一版畢業紀念冊那種懷舊翻書。
- **Don't** 用金箔漸層做一般背景或按鈕；金箔只給卡包、金卡、獎座。
- **Don't** 在獎項緞帶和「撕開」以外用紅色。
- **Don't** 讓雷射彩虹蓋滿照片；照片區保持清楚。
